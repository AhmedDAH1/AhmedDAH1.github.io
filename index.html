SOAR-Lite

Security orchestration, automation and response

SOC analysts lose hours repeating the same triage steps: checking whether an IP is known to be malicious, escalating by hand, pasting indicators into reports. SOAR-Lite runs that whole chain automatically. In simulated incidents it cut response time from over 30 minutes to under two.

  • 53 automated tests with 84% coverage, run on every push through GitHub Actions
  • FastAPI, SQLAlchemy and Alembic on PostgreSQL or SQLite, packaged with Docker

More projects

  • Email Threat Analyzer

    Phishing detection

    Upload any .eml file and get a 0–100 threat score built from header, URL, attachment and content checks. Tested against 414 real phishing emails from the Nazario corpus, where it caught 73%, with a labeled set of legitimate emails to keep false positives in check.

  • Log Threat Detector

    SIEM-style log correlation

    Live

    Reads SSH, Apache and syslog files to spot brute-force attempts, port scans and unusual activity, then correlates events across sources to surface attack patterns. Includes a real-time dashboard, AbuseIPDB enrichment and email alerts.

    Python, Flask, WebSockets, SQLite, AbuseIPDB API, Docker

  • Network Scanner

    Network reconnaissance

    Live

    Finds hosts with ARP and ICMP, scans ports with multi-threaded SYN and UDP probes, guesses operating systems from TTL values, and looks up device vendors and known CVEs. Runs in Docker with only the NET_RAW capability instead of full privileged mode.

    Python, Scapy, Flask, Docker

    Live demo Source

  • Attack Surface Mapper

    Security assessment

    Scans for vulnerabilities, maps findings to MITRE ATT&CK techniques, and checks them against PCI-DSS v4.0, NIST CSF and CIS Controls v8. Works from the command line, a terminal dashboard or a web interface, with Shodan exposure checks and reports in PDF, HTML, CSV or JSON.

    Python, Flask-SocketIO, MITRE ATT&CK, Shodan, 23 tests

  • Sigma Detection Rules

    Detection engineering

    In progress

    A small, carefully tested set of Sigma rules. Each rule is checked against recorded attack telemetry to confirm it fires, and against normal system activity to confirm it stays quiet. A CI pipeline lints the rules and converts them for Elastic, Splunk and Microsoft Sentinel.

    Sigma, GitHub Actions, Zircolite, Chainsaw
